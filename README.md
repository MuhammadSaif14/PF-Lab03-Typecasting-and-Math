# PF Lab 03 – Typecasting and Math

This repository contains my solutions for **Lab#03** of the course **CL-1002 Programming Fundamentals** (FAST-NUCES, Fall 2026), taught by Sir Muhammad Aais Rabbani.

All programs are written in **C**, using `printf`, `scanf`, `float`, explicit typecasting, and `sqrt` from `math.h` where needed.

## Programs Included
1. **Average Speed** – calculates speed using hours and distance travelled.
2. **Swapping Two Values** – swaps two integers and displays them.
3. **Salary After Tax** – calculates tax amount and net salary after deduction.
4. **Converting Pennies into Coins** – converts 368 pennies into the least number of quarters, dimes, nickels, and pennies.
5. **Roots of a Quadratic Equation** – solves `ax² + bx + c = 0` using the quadratic formula.
6. **Typecasting Before and After Division** – compares `a/b`, `(float)a/b`, and `(float)(a/b)`.
7. **Average Marks Using Typecasting** – calculates average of three subjects' marks using explicit cast.
8. **Converting a Float to an Integer** – shows the difference between a float value and its casted integer.

## How to Run
```bash
gcc filename.c -o output -lm
./output
```
(`-lm` is required for programs using `sqrt`, e.g. Question#5)
